# Web Development Foundations

A simple page for learning HTML structure, CSS styling, and JavaScript interaction.

## Run

Open `index.html` in a browser. No dependencies or build step are required. Click **Show greeting** to try the JavaScript interaction.

## Files

- `index.html`: semantic page structure.
- `styles.css`: page styling.
- `main.js`: button interaction.

If Node.js is available, run `npm run check` to check JavaScript syntax. The `package.json` file provides this convenience command; the page itself does not require Node.js.
